Urban Cart: MERN eCommerce store

Live, deployed, and built end to end by me.

Summary in three lines

  • Urban Cart is a full stack eCommerce store built with MongoDB, Express, React and Node.js.
  • Customers browse products, log in, fill a cart and pay in test mode, while an admin manages the catalogue.
  • It runs live on Vercel (frontend), Render (API) and MongoDB Atlas (database).

The problem

Small sellers need one simple place to manage products, stock, customer accounts and payments. Customers want a fast catalogue, a safe login and a clear checkout.

The idea

A lightweight store with two sides: a storefront for customers and a protected admin page for the owner. Everything is connected through one REST API and one database.

Customer

  • Product catalogue with search and category filters
  • Sign up and log in with JWT sessions
  • Shopping cart with live item count
  • Razorpay test-mode checkout, verified on the server
  • Order history under "My orders"

Admin and platform

  • Admin-only page to add, edit and delete products
  • Role check on protected API routes
  • Passwords stored as hashes, never as plain text
  • Seed script for sample products and an admin account
  • Secrets kept in environment variables, not in GitHub
